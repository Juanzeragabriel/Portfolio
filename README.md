Descrição do projeto

Portfólio profissional desenvolvido para apresentar meu perfil, formação acadêmica, conhecimentos em tecnologia e projetos realizados durante meus estudos em Desenvolvimento de Sistemas.

Tecnologias utilizadas:
HTML5
CSS3
Bootstrap
GitHub
GitHub Pages
Visual Studio Code

Link do site:
https://juanzeragabriel.github.io/Portfolio/

O site possui três seções principais:

Perfil: apresenta informações profissionais, formação e tecnologias estudadas.

Projetos: apresenta trabalhos desenvolvidos e links para os repositórios no GitHub.

Contato: disponibiliza links para e-mail, GitHub e LinkedIn.

O portfólio possui menu de navegação, carrossel de imagens e layout responsivo.

Novos recursos e melhorias

Foi utilizada a tag <style> para personalizar a fonte e as cores dos textos da página por meio do CSS.

Também foram realizadas melhorias no layout e no design, com a aplicação de um tema azul neon, efeitos visuais nos botões e cards, centralização dos elementos e ajustes no espaçamento para melhorar a apresentação do portfólio.
